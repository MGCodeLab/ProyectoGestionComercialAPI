# Paused Plans

Planes pausados temporalmente. Pueden reactivarse cuando se resuelvan dependencias o cambien prioridades.

## Convención

Mover un plan a esta carpeta cuando:
- Se detecta un bloqueante que impide progreso
- Se decide posponer trabajo para próxima iteración
- Se requiere información o decisión externa antes de continuar

Formato: `YYYY-MM-DD_titulo-plan.md`
