# Archived Plans

Planes completados o supersedidos que no volverán a ejecutarse. Mantenidos como referencia histórica.

## Convención

Mover un plan a esta carpeta cuando:
- El plan ha sido completado exitosamente (también crear summary en History Changed)
- El plan fue reemplazado por una versión mejorada
- El plan quedó obsoleto por cambios arquitectónicos

Formato: `YYYY-MM-DD_titulo-plan.md`
