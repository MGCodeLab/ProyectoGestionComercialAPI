# Release Notes

## Version v3.0.0 (Next Release)

### Strategic Objective

Consolidar la transición desde una API funcional hacia una plataforma comercial enterprise preparada para producción real y crecimiento modular.

### Main Focus

* Módulo Clientes
* Base sólida para Ventas
* Estándares de auditoría
* Gobernanza técnica con IA
* Preparción para frontend Angular

### Architectural Decisions

* Clean Architecture mantenida
* CQRS pragmático (Commands con MediatR / Queries con Services)
* INT interno + GUID público
* Soft Delete obligatorio
* Auditoría obligatoria
* FK con Restrict
* Controllers delgados
* Middleware global
* Response Wrapper estándar

### Expected Impact

* Base estable para expansión comercial
* Mejor trazabilidad
* Menor deuda técnica futura
* Escalabilidad real para clientes empresariales
